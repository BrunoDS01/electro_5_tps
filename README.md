# electro_5_tps
En este repositorio, se encuentra subido el proyecto completo, junto con su respectiva consigna e informe final; correspondiente al trabajo práctico de la materia Electrónica 5.

En el mismo, se programó en Verilog a través de Quartus Prime, un procesador ERV25, con su set de instrucciones RISC-V RV32I simplificado.

Se agregó un predictor de saltos consistente de una tabla con un contador de 2 bits para la predicción.
